Налаштування складалося з 7 сенсорних вузлів і одного крайового вузла в конфігурації зірки з сенсорними вузлами, які передають дані на край кожні 30 секунд за допомогою бездротових приймачів. Жодна система HVAC не використовувалася під час збору набору даних. У цьому експерименті використовувалися п’ять різних типів неінтрузивних датчиків: датчики температури, світла, звуку, CO2 і цифрові пасивні інфрачервоні (PIR). Датчики CO2, звуку та PIR потребували ручного калібрування. Для датчика CO2 калібрування за нульовою точкою було виконано вручну перед його першим використанням, витримуючи його в чистому середовищі протягом понад 20 хвилин, а потім потягнувши калібрувальний штифт (штифт HD) протягом 7 с. Датчик звуку, по суті, є мікрофоном із підключеним до нього аналоговим підсилювачем зі змінним коефіцієнтом посилення. Таким чином, вихід цього датчика є аналоговим, який зчитується мікроконтролером АЦП у вольтах. Потенціометр, пов'язаний з посиленням підсилювача, був налаштований для забезпечення найвищої чутливості. Датчик PIR має два регулятори: один для налаштування чутливості, а інший для налаштування часу, протягом якого вихідний сигнал залишається високим після виявлення руху. Обидва вони були скориговані до найвищих значень. Сенсорні вузли S1-S4 складалися з датчиків температури, світла та звуку, S5 мав датчик CO2, а S6 і S7 мали по одному датчику PIR, які були розгорнуті на виступах стелі під кутом, який максимізував поле зору датчика для виявлення руху.Інформація про атрибути:Date: YYYY/MM/DD

Висновок: Під час виконання цього завдання було успішно класифіковано набір даних "Room Occupancy Estimation" за допомогою дерев рішень та бібліотек rpart та c50.  Для нашого набору  досягнено точності на рівні 98%. Цей метод може бути корисним для класифікації великих наборів даних з багатьма ознаками та варіантами класів. Отже, класифікація за допомогою дерева рішень є ефективним методом для розв'язання задач класифікації, особливо коли маємо велику кількість ознак та об'єм даних. При цьому, вибір конкретної бібліотеки залежить від характеристик даних та потреб користувача.

library(caret)

# Завантаження даних
url <- "http://archive.ics.uci.edu/ml/machine-learning-databases/00640/Occupancy_Estimation.csv"
data <- read.csv(url)
# Видаляємо непотрібні колонки
data <- data[, 3:ncol(data)]

dependent_var <- "Room_Occupancy_Count"
independent_vars <- setdiff(colnames(data), dependent_var)

set.seed(123)  # Для відтворюваності результатів
train_indices <- sample(1:nrow(data), 0.8 * nrow(data))
train_data <- data[train_indices, ]
test_data <- data[-train_indices, ]


# 3.Провести класифікацію за допомогою дерева рішень, використовуючи бібліотеки rpart та C50 та оцінка точності
library(rpart)
library(rpart.plot)

model_rpart <- rpart(Room_Occupancy_Count~., data = train_data, method = "class")

rpart.plot(model_rpart, extra=106)
prediction <-predict(model_rpart, test_data, type = 'class')
table_mat <- table(test_data$Room_Occupancy_Count, prediction)
table_mat
accuracy_Test <- sum(diag(table_mat)) / sum(table_mat)
accuracy_Test
# або 
accuracy <- mean(predict(model_rpart, test_data, type = "class") == test_data$Room_Occupancy_Count)
accuracy

library(C50)
train_data$Room_Occupancy_Count <- factor(train_data$Room_Occupancy_Count)
model_c50 <- C5.0(Room_Occupancy_Count~., data = train_data)
model_c50

summary(model_c50)

room_pred <- predict(model_c50, test_data)

library(gmodels)
CrossTable(test_data$Room_Occupancy_Count, room_pred,
           prop.chisq = FALSE, prop.c = FALSE, prop.r = FALSE,
           dnn = c('actual default', 'predicted default'))

accuracy_c50 <- mean(predict(model_c50, test_data) == test_data$Room_Occupancy_Count)
