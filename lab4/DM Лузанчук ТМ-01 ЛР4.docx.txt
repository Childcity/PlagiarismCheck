Оцінити точність.Помилка "Metric Accuracy not applicable for regression models" виникає через те, що метрика "Accuracy" застосовується тільки для задач класифікації, а не для задач регресії. У вашому випадку, ви працюєте зі змінною "quality", яка є змінною регресії (цільовою змінною з числовими значеннями), тому метрику "Accuracy" не можна використовувати безпосередньо.Для оцінки точності моедлі регресії, можете використовувати інші метрики, такі як середня квадратична помилка (Mean Squared Error, MSE) або коефіцієнт детермінації (Coefficient of Determination, R-squared).Ось оновлений код, який використовує метрику MSE:RCopy codelibrary(caret) # ... fit.svm <- train(quality ~ ., data = wine.training, method = "svmLinear", trControl = control) print(fit.svm) caret_predict <- predict(fit.svm, newdata = wine.validation) mse <- mean((caret_predict - wine.validation$quality)^2) print(paste("MSE of caret svm =", mse)) # ... Замість розрахунку точності з використанням sum(diag(confusion_matrix)) / sum(confusion_matrix), обчислюємо середню квадратичну помилку (MSE) за допомогою (caret_predict - wine.validation$quality)^2.За вказаними даними, отримано коефіцієнт детермінації (R-squared) рівний 0.354. Коефіцієнт детермінації відображає пропорцію дисперсії відгуку, яку можна пояснити моделлю. Значення 0.354 означає, що модель пояснює близько 35.4% варіації відгуку. Чим ближче значення до 1, тим краще модель пояснює дані. В даному випадку, коефіцієнт детермінації 0.354 свідчить про помірну здатність моделі пояснювати варіацію відгуку на основі вхідних ознак. Також можна сказати, що данні доволі схожі до робіт зданих раніше,  тому можна зробити висновок, що оцінка точності проведене вірно.5 Висновок.Під час лабораторної роботи було проведено регресійний аналіз за допомогою методу машин опорних векторів (SVM) з використанням бібліотеки caret. Метою аналізу було передбачити якість вина (quality) на основі навчального набору даних.У коді було імпортовано дані про червоне вино, розбито їх на навчальний та тестовий набори і проведено навчання моделі SVM з використанням лінійного ядра. Метрикою оцінки був використаний коефіцієнт детермінації (R-squared).Після тренування моделі було здійснено прогнозування якості вина для валідаційного набору даних, а також обчислено коефіцієнт детермінації (R-squared). Згідно з отриманими результатами, коефіцієнт детермінації становить 0.354. Це означає, що модель SVM, побудована на основі лінійного ядра, пояснює лише 35.4% варіації якості вина у валідаційному наборі даних.З таким значенням коефіцієнта детермінації можна зробити висновок, що модель не є дуже ефективною у прогнозуванні якості вина на основі навчального набору даних. Можливо, для отримання кращих результатів слід розглянути використання інших алгоритмів чи змінити параметри SVM, такі як тип ядра або параметри регуляризації.Код програми:library(caret)# Імпорт данихwine <- read.csv("http://archive.ics.uci.edu/ml/machine-learning-databases/wine-quality/winequality-red.csv", sep=";", header=TRUE)# Перегляд перших кількох рядків данихhead(wine)# Розбиття набору даних на навчальний та тестовийset.seed(128)wine.training.indicies <- createDataPartition(wine$quality, p = 0.6, list = FALSE)wine.training <- wine[wine.training.indicies, ]wine.validation <- wine[-wine.training.indicies, ]# Перегляд таблиці розподілу якості у вибірці навчанняtable(wine.training$quality)# Перегляд таблиці розподілу якості у вибірці валідаціїtable(wine.validation$quality)# Конфігурація контролю навчанняcontrol <- trainControl(method = "cv", number = 10)metric <- "Rsquared"# Машини опорних векторів з використанням бібліотеки caretfit.svm <- train(quality ~ ., data = wine.training, method = "svmLinear", metric = metric, trControl = control)print(fit.svm)# Прогнозування за допомогою навченого класифікатораcaret_predict <- predict(fit.svm, newdata = wine.validation)print(caret_predict)# Оцінка точності моделі регресії за допомогою коефіцієнта детермінації (R-squared)rsquared <- cor(caret_predict, wine.validation$quality)^2print(paste("R-squared =", rsquared))
