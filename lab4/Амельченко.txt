Набір даних складається з одинадцяти атрибутів. Перший є порядковим

type of glass (тип скла) - є класовим, тобто ознакою з міткою класу. В

Мета класифікації – визначення типу скла за його хімічними властивостями.

4) Провести класифікацію за допомогою машин опорних векторів,
використовуючи бібліотеки caret, e1071 та kernlab.
Почнемо з класифікації за допомогою бібліотеки caret.
Для реалізації такого способу потрібно спочатку визначити контрольні
параметри навчання моделі. В даному випадку ми використовуємо кросвалідацію з 10 блоками. Далі ми визначаємо метрику, яку будемо
використовувати для оцінки результатів класифікації. Сама класифікація
проходить за допомогою функції train(), де ми вказуємо нашу метрику,
контрольні параметри, а також обираємо метод “svmLinear” для моделі SVM
з лінійним ядром. Далі виконуємо прогнозування функцією predict() та
обраховуємо отримані результати.
Код:
control <- trainControl(method = "cv", number = 10)
metric <- "Accuracy"
fit.svm <- train(`Type of glass`~., data = traindata, method =
"svmLinear", metric = metric, trControl = control)
caret_predict <-predict(fit.svm,testdata)
confusion_matrix <- table(caret_predict, testdata$`Type of
glass`)
print(confusion_matrix)
accuracy1 <- sum(diag(confusion_matrix))/sum(confusion_matrix)
print(paste("accuracy of caret svm =",accuracy1*100,"%"))
Результат:
Точність – 77.27%.Класифікація за допомогою бібліотеки е1071
За допомогою функції svm() створюється модель SVM, в параметрі kernel ми
вказуємо лінійне ядро. Далі прогнозуємо класи використовуючи predict(),
розраховуємо та виводимо результати.
Код:
library("e1071")
svm_model <- svm(`Type of glass` ~ ., data=traindata,
kernel="linear")
pred = predict(svm_model,testdata)
tab = table(Predicted=pred, Actual = testdata$`Type of glass`)
print(tab)
accuracy2 <- sum(diag(tab))/sum(tab)
print(paste("accuracy of e1071 svm =",accuracy2*100,"%"))
Результат:
Точність становить 77.27%.
Класифікація бібліотекою kernlab
Для класифікації даною бібліотекою ми протестуємо два ядра – лінійне
(kernel = “vanilladot”) та ядро радіально-базисної функції (kernel =
“rbfdot”). Різниця між ними в тому, що лінійне ядро для границі
розподілення класів використовує прямі лінії, а ядро радіально-базисної
функції в свою чергу може створювати криві границі, що дозволяє моделі більш
гнучко адаптуватись до складних нелінійних структур даних.
Код для лінійного ядра:
library(kernlab)
classifier <- ksvm(`Type of glass` ~ ., data = traindata,
kernel = "vanilladot")
predictions <- predict(classifier, testdata)
cm <- table(predictions, testdata$`Type of glass`)
print(cm)
accuracy3 <- sum(diag(cm))/sum(cm)
print(paste("accuracy of ksvm with vanilla kernel
=",accuracy3*100,"%"))Результат:
Точність – 77.27%.
Код для ядра радіально-базисної функції:
classifier <- ksvm(`Type of glass` ~ ., data = traindata,
kernel = "rbfdot")
predictions <- predict(classifier, testdata)
cm <- table(predictions, testdata$`Type of glass`)
print(cm)
accuracy4 <- sum(diag(cm))/sum(cm)

Результат:
Точність дорівнює 81,818%.
