В.КИЇВ-2023Мета роботиОцінити точність класифікації за допомогою машин опорних векторів (SVM) на наборі даних, що відповідає заданому варіанту, і порівняти результати використовуючи бібліотеки caret, e1071 та kernlab.Завдання1. Імпортувати дані, що відповідають вашому варіанту, до системи R.wine <- read.csv("winequality.csv", header = TRUE)2. Проаналізувати дані, що відповідають вашому варіанту, і визначити мету класифікації та ознаку, яка містить мітку класу.Мета класифікації: визначення якості вина. Ознака, яка містить мітку класу, це «quality», яка містить середню оцінку зразка вина. Ця ознака є категоріальною та має 10 різних значень(у наборі даних використано тільки 6 з них). Мета аналізу даних – зрозуміти, які ознаки найбільше впливають на якість вина. У подальшому можна використовувати ці знання для класифікації нових зразків вина. 3. Розбити набір даних на навчальний та тестовий.wine.train.indexes <- createDataPartition(wine$quality, p = 0.75, list = FALSE)wine.train <- wine[wine.train.indexes,]wine.test <- wine[-wine.train.indexes,]table(wine.train$quality)table(wine.test$quality)4. Провести класифікацію за допомогою машин опорних векторів, використовуючи бібліотеки caret, e1071 та kernlab. У цьому завданні нам потрібно провести класифікацію за допомогою машин опорних векторів. Якщо коротко, машини опорних векторів є потужним і універсальним алгоритмом машинного навчання, який може бути застосований для багатьох завдань, включаючи класифікацію, регресію та виявлення аномалій. Роздивимося детальніше на різних бібліотеках мови Р. Перш за все перевіримо як справляється бібліотека caret. Код наведено нижче:wine.train$quality <- as.factor(wine.train$quality)wine.model <- train(quality ~ .,                      data = wine.train,                      method = "svmLinear",                      metric = "Accuracy",                      trControl = trainControl(method = "cv", number = 10))caret_svm <- predict(wine.model, wine.test)confusion_matrix <- table(caret_svm, wine.test$quality)print(confusion_matrix)accuracy_caret <- sum(diag(confusion_matrix)) / sum(confusion_matrix)print(paste("Точність caret svm =", accuracy_caret * 100, "%"))Результат зображено на рисунку  нижче:Як ми можемо побачити, точність методу помірна і складає 58%. Якби була більша кількість даних, модель могла б мати набагато більшу точність.Далі ми розглянемо класифікацію використовуючи бібліотеку e1071. Знизу наведений код:library("e1071")e1071_model <- svm(quality ~ ., data=wine.train, kernel="linear")e1071_svm <- predict(e1071_model, wine.test)confusion_matrix <- table(Predicted=e1071_svm, Actual = wine.test$quality)print(confusion_matrix)accuracy_e1071 <- sum(diag(confusion_matrix)) / sum(confusion_matrix)print(paste("Точність e1071 svm =", accuracy_e1071 * 100,"%"))Результати наведено на рисунку, який зображено нижче:Як ми можемо побачити, точність тут співпала з попереднім методом. Це цілком нормальне явище через декілька причин:Через те, що у цій лабораторній використовується лінійне ядро (kernel="linear") і method = "svmLinear", можливий такий варіант, що методи будуть працювати однаково.Через те, що набір є досить простим і невеликим.Тепер розглянемо способи з бібліотеки kernlab. Знизу наведений код для першого варіанту:library(kernlab)kernlab_model <- ksvm(quality ~ ., data = wine.train,                       kernel = "vanilladot")kernlab_svm <- predict(kernlab_model, wine.test)confusion_matrix <- table(kernlab_svm, wine.test$quality)print(confusion_matrix)accuracy_kernlab_1 <- sum(diag(confusion_matrix)) / sum(confusion_matrix)print(paste("Точність ksvm з використанням vanilla =", accuracy_kernlab_1 * 100,"%"))Фінальний результат можна побачити на рисунку:Знову ж таки, так як у нас ядро однакове і дані невеликі, цей метод дає нам таку саму точність як і 2 попередні. Тепер розглянемо метод з цієї бібліотеки, який буде уже відрізнятися по точності, адже він не буде лінійним. Його код наведено нижче:kernlab_model <- ksvm(quality ~ ., data = wine.train,                         kernel = "rbfdot")kernlab_svm <- predict(kernlab_model, wine.test)confusion_matrix <- table(kernlab_svm, wine.test$quality)print(confusion_matrix)accuracy_kernlab_2 <- sum(diag(confusion_matrix)) / sum(confusion_matrix)print(paste("Точність ksvm з використанням rbfdot =",accuracy_kernlab_2 * 100,"%"))Результати продемонстровано на рисунку:Як бачимо, точність і справді трохи більша ніж була до цього. Хоча, насправді, метод не завжди дає більшу точність. Фінальна точність досить сильно залежить від наданих даних.5. Оцінити та порівняти точність.Якщо говорити про точність, яку ми отримали, то все досить логічно. Перші три методи дали нам такі самі точності і матриці помилок, адже ми використовувати лише лінійне ядро. А от останній метод, був показаний для прикладу, що якщо застосувати не лише лінійне ядро, то можна добитися і кращої точності. Тому, для експериментів можна міняти method для бібліотеки caret, kernel для бібліотеки e1071 та kernel для бібліотеки kernlab. У цій лабораторній було наведено лінійне ядро.
