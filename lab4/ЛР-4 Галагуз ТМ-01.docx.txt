Згідно з інформацією на сайті, яка додається до датасету, таблиця містить такі стовпці:

name - ASCII subject name and recording number
MDVP:Fo(Hz) - Average vocal fundamental frequency
MDVP:Fhi(Hz) - Maximum vocal fundamental frequency
MDVP:Flo(Hz) - Minimum vocal fundamental frequency
MDVP:Jitter(%),MDVP:Jitter(Abs),MDVP:RAP,MDVP:PPQ,Jitter:DDP - Several measures of variation in fundamental frequency

DFA - Signal fractal scaling exponent
spread1,spread2,PPE - Three nonlinear measures of fundamental frequency variation

Класифікація з використанням бібліотеки e1071:

Бібліотека e1071 використовує принципи машинного навчання для побудови моделей, зокрема методів опорних векторів (SVM), для класифікації та регресії.Отримана точність: 81.5789473684211 %. Це вказує на те, що модель добре працює на даному наборі даних і може правильно передбачати клас для близько 81% прикладів.Класифікація з використанням бібліотеки kernlab за допомогою ядра vanilladot:Показник точності є точно таким ж, як при використанні бібліотеки e1071. Даний показник, як було сказано, є досить хорошим.Класифікація з використанням бібліотеки caret:Показник точності є чудовим, оскільки він навіть вищий, ніж при використанні двох попередніх бібліотек.Висновок
Під час виконання лабораторної роботи було проведено аналіз даних, а саме – класифікація даних за допомогою машин опорних векторів,використовуючи бібліотеки caret, e1071 та kernlab. Після обчислення точності виявилось, що вона є доволі високою у всіх трьох моделях.Лістинг програми

filename <- "~/data/parkinsons.data"dataset <- read.csv(filename, header=TRUE)dataset$status = as.factor(dataset$status)dataset <- subset(dataset, select = -c(1))table(dataset$status)str(dataset)set.seed(123)library(caret)index <- createDataPartition(dataset$status, p = 0.8,list = FALSE)dataset_train <- dataset[index, ]dataset_test  <- dataset[-index, ]table(dataset_train$status)table(dataset_test$status)library("e1071")svm_model <- svm(status ~ ., data=dataset_train, kernel="linear") pred = predict(svm_model,dataset_test)tab = table(Predicted=pred, Actual = dataset_test$status)print(tab)accuracy2 <- sum(diag(tab))/sum(tab)print(paste("Accuracy of svm with e1071 =",accuracy2*100,"%"))library(kernlab)classifier <- ksvm(status ~ ., data = dataset_train, kernel = "vanilladot")predictions <- predict(classifier, dataset_test)confmatr <- table(predictions, dataset_test$status)print(confmatr)accuracy3 <- sum(diag(confmatr))/sum(confmatr)print(paste("Accuracy of svm with kernel =",accuracy3*100,"%"))library(caret)ctrl <- trainControl(method = "cv", number = 5)caretModel <- caret::train(status ~ ., data = dataset_train, method = "svmRadial",                  trControl = ctrl)pred = predict(caretModel,dataset_test)tab = table(Predicted=pred, Actual = dataset_test$status)print(tab)accuracy5 <- sum(diag(tab))/sum(tab)print(paste("Accuracy of svm with caret =",accuracy5*100,"%"))
