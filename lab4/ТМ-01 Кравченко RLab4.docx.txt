	Використаємо пакет `caret`:1. `control <- trainControl(method = "cv", number = 10)`: Створює об'єкт `control` для контролю тренування моделі. Використовується метод перехресної перевірки (cross-validation) з 10 фолдами.2. `metric <- "Accuracy"`: Встановлює змінну `metric` як "Accuracy", що вказує на використання точності як метрики для оцінки моделі.3. `fit.svm <- train(V1~., data = wine_train, method = "svmLinear", metric = metric, trControl = control)`: Тренує модель методом опорних векторів (SVM) з лінійною ядром (svmLinear) за допомогою функції `train`. Використовує дані з набору `wine_train`, де `V1` є цільовою змінною. Вказується також метрика для оцінки (`metric`) і об'єкт `control` для контролю тренування.4. `caret_predict <- predict(fit.svm, wine_test)`: Застосовує отриману модель на наборі `wine_test` для прогнозування класів. Результати зберігаються у змінну `caret_predict`.5. `conf_matrix <- table(caret_predict, wine_test$V1)`: Створює таблицю спряженості (`confusion matrix`) для порівняння прогнозованих значень `caret_predict` з фактичними значеннями цільової змінної `wine_test$V1`.6. `accuracy1 <- sum(diag(conf_matrix))/sum(conf_matrix)`: Обчислює точність моделі, використовуючи значення на головній діагоналі (`diag`) таблиці спряженості. Результат зберігається у змінну `accuracy1`.7. `accuracy1*100`: Виводить точність моделі у відсотковому виразі, помножену на 100.		Використаємо пакет `e1071`:1. `library(e1071)`: Завантажує пакет 'e1071', який містить реалізацію алгоритму опорних векторів (SVM).2. `svm_model <- svm(V1~., data = wine_train, kernel = "linear")`: Створює модель опорних векторів (SVM) з використанням функції `svm`. Вираз `V1~.` вказує, що змінна `V1` є цільовою змінною, а всі інші змінні в наборі даних `wine_train` є предикторами. Вказується також ядро моделі (`kernel = "linear"`), яке в даному випадку є лінійним.3. `pred <- predict(svm_model, wine_test)`: Виконує прогнозування на наборі даних `wine_test` з використанням створеної моделі опорних векторів. Результати прогнозу зберігаються у змінну `pred`.4. `tab <- table(Predicted = pred, Actual = wine_test$V1)`: Створює таблицю спряженості (`confusion matrix`) для порівняння прогнозованих значень `pred` з фактичними значеннями цільової змінної `wine_test$V1`.5. `accuracy2 <- sum(diag(tab))/sum(tab)`: Обчислює точність моделі, використовуючи значення на головній діагоналі (`diag`) таблиці спряженості. Результат зберігається у змінну `accuracy2`.6. `accuracy2*100`: Виводить точність моделі у відсотковому виразі, помножену на 100.
	Використаємо пакет `kernlab`: 1. `classifier <- ksvm(V1~., data = wine_train, kernel = "vanilladot")`: Створює модель опорних векторів (SVM) з використанням функції `ksvm` з ядром "vanilladot". Вираз `V1~.` вказує, що змінна `V1` є цільовою змінною, а всі інші змінні в наборі даних `wine_train` є предикторами.2. `prediction <- predict(classifier, wine_test)`: Виконує прогнозування на наборі даних `wine_test` з використанням створеної моделі опорних векторів. Результати прогнозу зберігаються у змінну `prediction`.3. `cm <- table(prediction, wine_test$V1)`: Створює таблицю спряженості (`confusion matrix`) для порівняння прогнозованих значень `prediction` з фактичними значеннями цільової змінної `wine_test$V1`.4. `cm`: Виводить таблицю спряженості.5. `accuracy3 <- sum(diag(cm))/sum(cm)`: Обчислює точність моделі, використовуючи значення на головній діагоналі (`diag`) таблиці спряженості. Результат зберігається у змінну `accuracy3`.6. `accuracy3*100`: Виводить точність моделі у відсотковому виразі, помножену на 100.5. Оцінити точність.
