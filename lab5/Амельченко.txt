1) Проаналізувати дані, що відповідають вашому варіанту, і визначити мету
класифікації та ознаку, яка містить мітку класу.
Завдання за варіантом – Haberman’s Survival.
http://archive.ics.uci.edu/dataset/43/haberman+s+survival
Набір даних складається з чотирьох атрибутів та описує пацієнтів з
онкологічним захворюванням. Перший атрибут – вік пацієнта на момент
операції, другий – рік проведення операції, третій – кількість метастаз ,
четвертий – прогноз щодо пацієнта на наступні п’ять років (1 – позитивний, 2
– негативний). Власне останній атрибут є ознакою з міткою класу.
Мета класифікації – прогноз стану пацієнта, котрий базується на його віці,
даті проведення операції та кількості метастаз.

filename <- "~/data/haberman.data"
dataset <- read.csv(filename, header=FALSE)
head(dataset)
colnames(dataset) <- c("Age","Year","Nodes","Status")
set.seed(91)
dataset$Status <- ifelse(dataset$Status == 2, 0, 1)
ran <- sample(1:nrow(dataset), 0.7 * nrow(dataset))
traindata <- dataset[ran, ]
testdata <- dataset[-ran, ]
prop.table(table(traindata$Status))
prop.table(table(testdata$Status))
model_glm = glm(Status ~., data = traindata, family = "binomial")
coef(model_glm)
head(predict(model_glm, type = "link"))
head(predict(model_glm, type = "response"))
model_glm_pred = ifelse(predict(model_glm, type = "link") > 0, 1,
0)
train_tab = table(predicted = model_glm_pred, actual =
traindata$Status)
library(caret)
train_con_mat = confusionMatrix(train_tab)
c(train_con_mat$overall["Accuracy"],
train_con_mat$byClass["Sensitivity"],
train_con_mat$byClass["Specificity"])
library(pROC)
test_prob = predict(model_glm, newdata = testdata, type =
"response")
test_roc = roc(testdata$Status ~ test_prob, plot = TRUE, print.auc
= TRUE)
