Модель має гарну чутливість, однак специфічність нижча, що може вказувати на те що модель частіше правильно виявляє позитивний клас, але може частіше помилятися при виявленні негативного класу. Точність та позитивна прогностична цінність є високими, що вказує на здатність моделі ефективно класифікувати дані.Площа під ROC-кривою (AUC) для моделі дорівнює 0.8481. Це досить високе значення, що вказує на те, що модель має гарну дискримінаційну здатність. AUC більше 0.5, а це значить що модель виконує краще, ніж випадкове вгадування.Код усієї програми# Константа з назвою файла для завантаженняfilename <- "diabetes.csv"# Імпорт даних з файлуdataset <- read.csv(filename, sep=",", header=TRUE)# Перевірка структури данихstr(dataset) # Отримання статистичних данихsummary(dataset)# Заміна помилкових значень на NAcols_to_check <- c("Glucose", "BloodPressure", "SkinThickness", "Insulin", "BMI")dataset[cols_to_check] <- lapply(dataset[cols_to_check], function(x) ifelse(x == 0, NA, x))# Видалення рядків з NAdataset_clean <- na.omit(dataset)# Перевірка структури даних після очищенняstr(dataset_clean)# Отримання статистичних даних після очищенняsummary(dataset_clean)# Встановлення назви мітки цільового класуtarget_label <- 'Outcome'# Завантаження бібліотеки caret для розбиття даних і оцінювання моделіlibrary(caret)# Встановлення зерна генератора випадкових чисел для відтворюваності результатівset.seed(123)# Розбиття даних на навчальний і тестовий набори (75% даних для тренування, 25% даних для тесту)index <- createDataPartition(dataset_clean[[target_label]], p=0.75, list=FALSE)# Створення навчального набору данихdata_train <- dataset_clean[index, ]# Створення тестового набору данихdata_test <- dataset_clean[-index, ]# Створення формули, де target_label - цільова змінна, а "~ ." - всі інші як предикториformula <- as.formula(paste(target_label, "~ ."))# Навчання моделі логістичної регресіїlogistic_model <- glm(formula, data = data_train, family = "binomial")# Прогнозування на тестовому наборі данихpredictions <- predict(logistic_model, newdata = data_test, type = "response")# Перетворення прогнозованих імовірностей в класові міткиpredicted_labels <- ifelse(predictions > 0.5, 1, 0)# Обчислення матриці помилокconfusion_matrix <- confusionMatrix(as.factor(predicted_labels), as.factor(data_test$Outcome))# Виведення точності моделіaccuracy <- confusion_matrix$overall['Accuracy']print(confusion_matrix)print(paste("Accuracy of the logistic regression model:", accuracy * 100, "%"))library(pROC)# Побудова ROC-кривої та обчислення показника AUCroc_curve <- roc(data_test$Outcome, predictions)print(roc_curve)plot(roc_curve, main="ROC Крива")Висновки

Ми розглянули датасет, який містить медичні дані пацієнтів та їх стан щодо діабету. Після очищення та підготовки даних, було розроблено модель логістичної регресії за допомогою бібліотеки caret та оцінена її ефективність. Точність моделі складала 83.67%, що є досить хорошим показником. Також була побудована ROC-крива та обчислено площу під цією кривою (AUC), яка дорівнює приблизно 0.8481. Це підтверджує високу дискримінаційну здатність моделі та її здатність ефективно розрізняти між класами.
