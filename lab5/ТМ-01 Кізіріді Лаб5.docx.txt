Вона використовує функцію predict() для отримання ймовірностей прогнозів моделі на нових даних. На основі заданого порогу cut, вона класифікує прогнози як позитивний (pos) або негативний (neg) клас. Потім вона викликає написану раніше функцію calc_class_err() для обчислення помилки класифікації між фактичними значеннями та передбаченими значеннями.# Функція для обчислення помилки моделіget_logistic_error <- function(mod, data, res = "y", pos = 1, neg = 0, cut = 0.5) {  probs <- predict(mod, newdata = data, type = "response")  preds <- ifelse(probs > cut, pos, neg)  calc_class_err(actual = data[, res], predicted = preds)
}За допомогою наступних рядків перетворюємо цільову змінну Class у числовий формат. Тут використовується функція as.numeric() для отримання числового вектору, від якого потім віднімається 1. Це здійснюється для того, щоб класи стали числовими значеннями, які можна використовувати в моделі.# Конвертація цільової змінної в числовий форматleaves_train$Class <- as.numeric(leaves_train$Class) - 1leaves_test$Class <- as.numeric(leaves_test$Class) - 1Останні рядки цього алгоритму використовують пакет pROC для побудови ROC-кривої та обчислення AUC (Area Under the Curve) для моделі model_glm на тестовому наборі leaves_test. Функція predict() визначає ймовірності прогнозів моделі вже на нових даних. За допомогою функції roc() визначається ROC-крива, передаючи цільову змінну leaves_test$Class та ймовірності прогнозів test_prob. Аргументи plot = TRUE та print.auc = TRUE вказують на побудову графіка ROC-кривої та виведення значення AUC в консоль відповідно.library(pROC)test_prob <- predict(model_glm, newdata = leaves_test, type = "response")test_roc <- roc(leaves_test$Class ~ test_prob, plot = TRUE, print.auc = TRUE)Результатом виконання алгоритму є така ROC-крива:
