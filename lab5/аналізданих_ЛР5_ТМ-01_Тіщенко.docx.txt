Проаналізувати дані, що відповідають вашому варіанту, і визначити мету класифікації та ознаку, яка містить мітку класу.Мета класифікації: Визначити, чи є об'єкт сигналом (R - "rock") або міною (M - "mine").Ознаки:- "0.0200", "0.0371", "0.0428", ..., "0.0090": числові ознаки для класифікації.Мітка класу: V612. Імпортувати дані, що відповідають вашому варіанту, до системи R.# URL для завантаження даних> url <- "http://archive.ics.uci.edu/ml/machine-learning-databases/undocumented/connectionist-bench/sonar/sonar.all-data"> > # Імпортувати дані> data <- read.csv(url, header = FALSE)3. Розбити набір даних на навчальний та тестовий.# Розмір навчального набору даних> train_size <- 0.7> > # Розбиття на навчальний та тестовий набори> train_idx <- sample(nrow(data), floor(train_size * nrow(data)))> train_data <- data[train_idx, ]> test_data <- data[-train_idx, ]4. Провести класифікацію за допомогою логістичної регресії.
> # Підготовка даних> x_train <- as.matrix(train_data[, -ncol(train_data)])> y_train <- as.factor(train_data[, ncol(train_data)])> > # Побудова моделі логістичної регресії> model_glm <- glmnet(x_train, y_train, family = "binomial")5. Оцінити та порівняти точність.# Прогнозування класу> predictions <- predict(model_glm, newx = as.matrix(test_data[, -ncol(test_data)]), type = "class")> > # Обчислення точності> accuracy <- mean(predictions == test_data[, ncol(test_data)])> > # Виведення точності> print(paste("Accuracy:", accuracy))[1] "Accuracy: 0.725555555555556"6. Побудувати ROC-криву та обчислити показник AUC.# Обчислення ймовірностей> probabilities <- predict(model_glm, newx = as.matrix(test_data[, -ncol(test_data)]), type = "response")> > response <- ifelse(test_data[, ncol(test_data)] == "R", 0, 1)> probabilities <- as.numeric(probabilities[1:63])> > # Перевірка розмірів векторів> length(response)[1] 63> length(probabilities)[1] 63> > # Побудова ROC-кривої та обчислення AUC> roc_obj <- roc(response, probabilities)Setting levels: control = 0, case = 1Setting direction: controls < cases> > library(pROC)> > # Візуалізація ROC-кривої> plot(roc_obj, col = "dodgerblue", main = "ROC Curve")> abline(a = 0, b = 1, lty = 2, col = "darkorange")> > > # Виведення AUC> print(paste("AUC:", auc(roc_obj)))[1] "AUC: 0.5"Висновок: при виконанні даної лабораторної роботи було проведено класифікацію даних за допомогою логістичної регресії.
