Також, на графіках топології ми можемо побачити, що модель з прихованим шаром використовувала 755 кроків, тоді як модель без прихованих шарів - 16646 кроків. Це може вказувати на те, що модель без прихованих шарів потребувала більше часу на оптимізацію. Однак, модель без прихованих шарів має трохи меншу сумарну помилку на навчальних даних.Код усієї програми# Константа з назвою файла для завантаженняfilename <- "seeds_dataset.txt"# Імпорт даних з файлуdataset <- read.csv(filename, sep="\t", header=FALSE)# Видалимо рядки, де є NAdataset_clean <- na.omit(dataset)# Перевірка структури данихstr(dataset_clean) # Отримання статистичних данихsummary(dataset_clean)# Встановлення назви мітки цільового класуtarget_label <- 'V8'# Завантаження бібліотеки caret для розбиття даних і оцінювання моделіlibrary(caret)# Встановлення зерна генератора випадкових чисел для відтворюваності результатівset.seed(123)# Створення формули, де target_label - цільова змінна, а "~ ." - всі інші як предиктори.formula <- as.formula(paste(target_label, "~ ."))# Функція для нормалізації данихnormalize <- function(x) {  return((x - min(x)) / (max(x) - min(x)))}# Нормалізація данихdataset_norm <- as.data.frame(lapply(dataset_clean, normalize))# Розбиття даних на навчальний і тестовий набори (75% даних для тренування, 25% даних для тесту)index <- У ході цієї лабораторної роботи ми дослідили побудову нейронних мереж для класифікації за допомогою мови програмування R. Було створено дві моделі нейронних мереж: одна з прихованим шаром та інша без прихованих шарів. Після тренування, моделі були оцінені на тестовому наборі даних. За результатами, модель без прихованих шарів демонструвала помилку 2.810926, а модель з одним прихованим шаром - помилку 3.429073. Це вказує на те, що модель без прихованих шарів трохи краще впоралась з завданням на навчальних даних. Однак, модель без прихованих шарів потребувала набагато більше кроків для оптимізації (16646 проти 755).
